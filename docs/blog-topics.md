# Blog topic queue

The blog routine takes the FIRST unticked line (`- [ ]`) on each run, writes it, and ticks it (`- [x]`) in the same pull request. The text in brackets is the main search phrase. `→` names the service page(s) the post must support. Add new topics at the end of the right section in the same format. The main search phrase must be informational ("how to", "checklist", "cost", "vs", "what can") and must NOT be the phrase a service page targets (e.g. "mattress removal sydney" belongs to /mattress-removal): the post links up to that page instead. "Best ..." topics are written as a buyer's checklist, never as NRR ranking itself. See docs/BLOG-CONTENT-PLAN.md for the reasoning and docs/BLOG-GUIDELINES.md for the rules.
